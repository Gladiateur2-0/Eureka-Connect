Tous les collaborateurs

Le fichier .vcf global contient les fiches de en un seul fichier :

    Sur Windows, un double-clic sur le fichier .vcf n'affiche que la première fiche : c'est une limite d'Outlook et de l'application Contacts de Windows. Le fichier contient pourtant bien tous les agents. Pour les ajouter tous d'un coup :
    • Google Contacts / Gmail : contacts.google.com → Importer → choisir le fichier .vcf.
    • Outlook (Windows) : utilisez la Version Outlook (CSV), puis Fichier → Ouvrir et exporter → Importer/Exporter → « Importer à partir d'un autre programme ou fichier » → Valeurs séparées par une virgule.
    • Outlook.com / Outlook web : Contacts → Gérer les contacts → Importer des contacts → fichier CSV.
    • iPhone / Android : ouvrez le fichier .vcf sur le téléphone, puis « Ajouter tous les contacts ».
